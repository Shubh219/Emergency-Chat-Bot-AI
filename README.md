# Emergency-Chat-Bot-AI
Savi – The Emergency Chatbot Savi is a smart, AI-driven emergency chatbot designed to assist users during critical situations by providing immediate, context-aware support. Whether it's a medical emergency, natural disaster, or fire hazard, Savi helps users stay informed and take quick action.

🌟 Core Features
🧠 NLP-Enabled Conversations – Uses AI to interpret user input and deliver accurate emergency responses.

📍 Location-Aware Help – Fetches the user's real-time location to connect them with the nearest emergency services.

🚨 Emergency Scenarios Support – Covers a wide range of emergencies like fire, injury, panic attacks, natural disasters, etc.

🔔 Real-Time Alerts & Instructions – Gives actionable steps and guidance during urgent situations.

🔐 User Privacy Focused – Minimal data retention, optional anonymity, and secure handling of sensitive interactions.

Personal emergency apps

Safety tools for schools and colleges

Disaster relief support
